## Installer et se connecter

L'application **GLOBUS Client** (Android et iPhone) reprend toutes les fonctions de votre espace client : mêmes données, mêmes droits, mêmes validations.

1. Installez l'application fournie par GLOBUS ENGINEERING, puis ouvrez-la.
2. Saisissez votre adresse e-mail et votre mot de passe, cochez **Rester connecté** sur votre téléphone personnel, puis **Se connecter**.
3. Saisissez le code à 6 chiffres de votre application d'authentification puis **Vérifier**. Sans votre téléphone d'authentification, touchez **Utiliser un code de secours**.
4. Première connexion : ouvrez le lien d'invitation reçu par e-mail ou WhatsApp directement sur le téléphone (ou touchez **J'ai reçu un lien d'activation** et collez-le), choisissez votre mot de passe puis **Activer et continuer**.

> [!NOTE]
> Votre compte est protégé par la double authentification. Si elle n'est pas encore activée, l'application ouvre directement **Mon compte › Sécurité** : touchez **Configurer une application d'authentification**, puis **Ouvrir l'application d'authentification** (sur le même téléphone) ou scannez le QR code depuis un autre appareil, et saisissez le code affiché.

## Se repérer

- **Barre du bas** : **Accueil** (tableau de bord), **Chantier**, **Finances**, **Messages** et **Plus** (toutes les autres rubriques).
- **Menu ☰** en haut à gauche des pages principales : la liste complète, identique à celle du site.
- **Projet** : sous la barre du haut, touchez le nom du projet pour changer de projet si vous en avez plusieurs.
- **Cloche** : vos notifications ; une notification reçue pendant l'utilisation s'affiche aussi en bas de l'écran avec **Voir**.
- Tirez la page vers le bas pour la rafraîchir.

## Hors ligne

Les pages déjà consultées restent lisibles sans réseau : un bandeau orange **Hors ligne — données du …** indique la date des informations affichées. Les actions (paiement, validation, message, demande SAV) exigent une connexion. Les données enregistrées sur le téléphone sont chiffrées et effacées à la déconnexion.

## Notifications push

Dans **Mon compte › Notifications**, touchez **Activer le push** puis autorisez les notifications du téléphone : vous êtes prévenu même application fermée (décisions à valider, paiements, messages, appels). **Envoyer une notification de test** vérifie le parcours ; **Désactiver sur ce téléphone** l'arrête pour cet appareil seulement. Toucher une notification ouvre directement l'écran concerné.

## Paiements, validations et appels

- **Payer** ouvre le choix du moyen de paiement ; Mobile Money : validez la demande sur votre téléphone avec votre code secret. L'écran de suivi affiche la confirmation et **Télécharger le reçu**.
- Les décisions, avenants, échéanciers et offres se valident par **code à usage unique** reçu par e-mail, SMS ou WhatsApp, comme sur le site.
- Les appels audio et vidéo fonctionnent depuis la **Messagerie** ou **Appels** ; un appel entrant s'affiche en haut de l'écran avec **Répondre** et **Refuser**. Pendant l'appel : micro, caméra, changement de caméra, haut-parleur, partage d'écran et consentement à l'enregistrement.

## Maquette 3D, configurateur et visites 360°

**Ouvrir la maquette 3D** affiche la maquette en plein écran (pivoter avec un doigt, zoomer en pinçant, calques par discipline, coupe). Dans le **Configurateur**, le choix d'un matériau met à jour l'aperçu 3D et les totaux ; touchez une surface de la maquette pour sélectionner sa zone. Les visites 360° suivent les mouvements du téléphone.

> [!TIP]
> En cas de perte ou de vol du téléphone, connectez-vous depuis un autre appareil puis **Mon compte › Sessions et appareils › Révoquer** : l'application est immédiatement déconnectée.
