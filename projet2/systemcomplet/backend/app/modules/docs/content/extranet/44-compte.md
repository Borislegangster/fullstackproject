## Accès

Menu **Échanges › Mon compte** (ou votre nom en haut à droite). Onglets **Profil**, **Sécurité**, **Sessions et appareils**, **Notifications**.

## Profil

**Informations personnelles** (**Prénom**, **Nom**, **Téléphone**, **WhatsApp**, **Fonction**, **Fuseau horaire**) puis **Enregistrer**. **Mot de passe** : **Mot de passe actuel**, **Nouveau mot de passe**, **Confirmation**, **Modifier le mot de passe** (vos autres sessions sont fermées).

## Sécurité : double authentification

1. **Configurer une application d'authentification** : scannez le QR code, saisissez le **Code à 6 chiffres**, **Activer**.
2. Conservez vos **codes de secours** (**Télécharger**, puis **J'ai conservé mes codes**).
3. **Ajouter une clé / biométrie** pour vous connecter avec une clé de sécurité ou l'empreinte du téléphone.
4. **Régénérer les codes de secours** si vous les avez utilisés ou perdus ; **Désactiver le MFA** (mot de passe et code demandés) est déconseillé.

### Confirmer une opération sensible

Certaines opérations (secrets des intégrations, réglages de sécurité) exigent une session confirmée par la double authentification. Si votre session ne l'est pas encore, la fenêtre **Confirmer avec votre double authentification** s'ouvre : saisissez le **Code à 6 chiffres de votre application d'authentification** (ou **Utiliser un code de secours**), puis **Confirmer** : l'opération reprend automatiquement et votre session reste confirmée. Sans double authentification active, **Activer la double authentification** ouvre cet onglet.

## Sessions et appareils

**Sessions actives** (**Révoquer**, **Fermer les autres sessions**), **Appareils** de confiance (30 jours sans second facteur ; **Révoquer**), **Historique de sécurité**.

## Notifications

Canaux par catégorie (Application, Push, E-mail, WhatsApp, SMS) ; **Activer le push** / **Désactiver le push sur ce navigateur**.

> Un collaborateur quitte votre entreprise : demandez à votre interlocuteur GLOBUS de désactiver son compte.
