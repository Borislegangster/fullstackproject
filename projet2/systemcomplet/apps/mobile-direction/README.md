# GLOBUS Direction (globus_direction)

Application mobile de la direction et des responsables GLOBUS ENGINEERING : tableau de bord, validations
(achats, commandes, paiements, situations, factures, congés, documents, actions QHSE), portefeuille de chantiers,
achats, sous-traitance, litiges, finance, commercial, RH, QHSE, administration — mêmes droits que l'ERP web.
Formulaires générés depuis l'OpenAPI (aucun identifiant ni JSON à saisir).

Voir `docs/MOBILE.md`.

```bash
flutter run --dart-define-from-file=config/dev.json
```
